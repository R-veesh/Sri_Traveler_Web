# 🌍 Sri Traveler Web (Guider Dashboard)

Sri Traveler Web is the **web-based dashboard for tour guiders** in the Sri Traveler ecosystem. It allows guiders to manage travel packages, handle user bookings, and communicate with travelers after booking confirmation.

This system works together with the Sri Traveler mobile application, creating a complete **tourism management platform for Sri Lanka**.

## 📌 Project Overview

Sri Traveler Web is designed for **tour guiders** to manage their travel services efficiently.

### 🧭 Main Purpose:
- Manage tour packages
- Handle booking requests from users
- Accept or reject trip requests
- Communicate with travelers after approval
- Maintain guider profile and availability

---

## 🧑‍💼 User Roles

### 🧭 Guider (Main Role)
- Create and manage travel packages
- View booking requests
- Accept / Reject bookings
- Chat with users after confirmation
- Manage trip availability

### 👤 Connected System (Mobile Users)
- Users book trips from mobile app
- Users request guiders
- After acceptance, chat is enabled

---

## 🔥 Key Features

### 📦 Package Management
- Create new travel packages
- Edit or delete existing packages
- Add trip details, locations, and descriptions

### 📑 Booking System
- View incoming booking requests
- Accept or reject bookings
- Track booking status (Pending / Accepted / Rejected)

### 💬 Chat System
- Direct communication with users
- Activated after booking acceptance
- Real-time interaction for trip planning

### 👤 Profile Management
- Update guider profile details
- Manage availability
- Display experience and services

## 🧠 System Workflow

1. Guider logs into web dashboard
2. Guider creates travel packages
3. Users send booking requests from mobile app
4. Guider receives booking request
5. Guider accepts or rejects request
6. If accepted:
   - Booking is confirmed
   - Chat system is activated
7. Guider and user communicate for trip arrangements
